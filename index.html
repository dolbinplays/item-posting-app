Recommended Recovery Workflow

  1. Export Full JSON Backup for app restore.
  2. Export Rebuildable HTML Backup for human-readable listing recovery with embedded photos.
  3. Export Sheets + Drive CSV as the Google Sheets inventory index.
  4. Export Media Manifest JSON to see the suggested Drive folder/file structure.
