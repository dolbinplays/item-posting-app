Sync & Backup

Keep Google Drive, Google Sheets, and local recovery files up to date from one place.

Google Sync

The usual path is simple: sign in, sync everything, then check health. Detailed setup and troubleshooting tools are still available below.

Shared Google Workspace

Use the same Google account on your phone and computer. This syncs lightweight inventory records through one JSON file in the Drive root folder. Full photos stay in Drive and browser-local camera media stays on the device that captured it.

Second-Device Setup Handoff

Copy this safe setup code from one device and paste it into another. It includes the non-secret Google OAuth Client ID, Drive and Sheet names, and recognition relay URL. It never includes Google access tokens, passwords, OpenAI keys, photos, or inventory.

Advanced Google setup and troubleshooting

Google Sync Settings

These names control direct Google Sheets + Drive sync, exports, and suggested Drive paths. They are saved in backups.

Google API Setup

Save the non-secret OAuth Client ID used by the Google sign-in button. Do not paste passwords or API secrets here.

Google Sign-In Test

This requests a temporary in-memory access token for the Sheets + Drive scopes. Signing in alone does not upload, edit, or store the token.

Google API Probe

After access is granted, this makes one read-only Drive API call to verify the token and API access. It does not create, upload, edit, or delete anything.

Google Drive Root Folder

Find or create the configured Drive root folder. This creates only one folder if no matching folder exists.

Google Drive Item Folders

Create or find item folders under the Drive root for ready items. Each run processes the next 3 ready items that do not already have folder links.

Google Drive Photo Upload

Upload best-available listing and storage photos for ready items that already have Drive folder links. New camera captures keep high-quality originals in the browser media library while the app uses smaller previews. Use one item for debugging or three items for the normal batch path.

Google Sync Next Batch

Run live sync in cautious batches. Next batch handles up to 3 folders and 3 photo-backed items. All remaining repeats that same batch loop and writes the Sheet at the end.

Google Sync Completion Report

Summarize which ready items are complete, still need folders, still need photo uploads, or still need Sheet link writing.

Google Sync Health Check

Verify the local sync record before relying on the Sheet: folder links, photo links, storage links, and any marked-complete inconsistencies.

Google Sheet Index

Find or create the configured Google Sheet and write the CSV header row only. Inventory rows are not written in this stage.

Google Sheet First Rows

Write ready inventory rows to the connected Sheet. Test mode writes 3 rows; full mode writes all readiness-passing rows and clears the old synced range first.

Google Sync Dry Run

This simulates a future Google Sheets + Drive sync without signing in or uploading anything.

Google Sync Readiness Gate

Checks each inventory item for the minimum data needed before direct Google Sheets + Drive sync is allowed.

Google Sync Action Queue

Preview the exact Sheets + Drive operations a sync run would perform.

Google Sync History

Save a local snapshot of the current dry run, readiness gate, and action queue so you can compare what changed before a live sync.

Google Sync Preflight

A final local safety check before live Google sync. This does not contact Google.

Google Sync Simulation

Run the current action queue locally and save a no-Google execution log. This helps test the future sync flow before live API access exists.

Google Authorization Requirements

Permissions used by direct Google Sheets + Drive sync. Google access tokens stay in memory only and are not written to browser storage or backups.
